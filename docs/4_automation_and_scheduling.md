# 4. 自動化與排程指南

本指南說明如何利用專案中提供的腳本，實現數據更新的自動化，並透過 Windows 工作排程器設定定時任務。

## 4.1 自動化腳本介紹

專案的 `scripts/` 目錄下提供了方便的批次檔 (`.bat`)，用於簡化日常操作。

*   `daily_update_task.bat`:
    *   **用途**: **推薦用於自動化排程**。
    *   **功能**: 此腳本會以非互動模式執行 `data_etl/integrated_updater.py`，自動完成「下載分鐘 K 線」及「生成所有週期 K 線」的完整流程。
    *   **日誌**: 所有執行輸出和錯誤訊息都會被導向到 `log/daily_task.log` 檔案，方便追蹤與除錯。

*   `run_cycle_updater.bat`:
    *   **用途**: 用於手動執行，不適合排程。
    *   **功能**: 提供一個互動式選單，讓您可以手動選擇要執行的更新任務，例如只更新最近 7 天的週期數據，或單獨執行整合更新。

## 4.2 設定每日自動更新排程

以下步驟將引導您使用 Windows 內建的「工作排程器」來設定每日自動執行數據更新。

### 步驟 1: 開啟工作排程器

*   按 `Win + R` 鍵，輸入 `taskschd.msc` 並按 Enter。
*   或在開始選單中搜尋「工作排程器」。

### 步驟 2: 建立工作

1.  在右側「動作」面板中，點擊「**建立基本工作...**」。
2.  **名稱**: 輸入一個易於識別的名稱，例如 `每日期貨數據更新`。
3.  **描述**: (選填) 填寫 `執行 capital_python 專案的每日數據更新任務`。
4.  點擊「下一步」。

### 步驟 3: 設定觸發程序

1.  選擇「**每天**」。
2.  設定一個適當的執行時間，例如 **下午 3:00:00** (台股收盤後)。
3.  點擊「下一步」。

### 步驟 4: 設定動作

1.  選擇「**啟動程式**」。
2.  點擊「下一步」。
3.  **填寫程式/指令碼資訊**:
    *   **程式或指令碼**: 點擊「瀏覽」，選擇專案中的 `scripts\daily_update_task.bat` 檔案。
        *   例如: `C:\Users\user\source\repos\capital_python\scripts\daily_update_task.bat`
    *   **開始位置 (選填)**: **請務必填寫專案的根目錄路徑**，以確保腳本能正確找到 Python 檔案。
        *   例如: `C:\Users\user\source\repos\capital_python`

    ![Task Scheduler Action Settings](https://i.imgur.com/wO5v2dC.png)

4.  點擊「下一步」。

### 步驟 5: 完成設定

1.  檢查摘要頁面中的資訊是否正確。
2.  勾選「**當我按一下 [完成] 時，開啟這個工作的 [內容] 對話方塊**」。
3.  點擊「完成」。

### 步驟 6: 進階設定 (重要)

1.  在開啟的「內容」視窗中，確保選擇「**不論使用者登入與否，均執行(W)**」。這能保證即使您登出 Windows，排程依然會執行。
2.  (可選) 切換到「條件」分頁，取消勾選「只有在電腦是使用 AC 電源時，才啟動工作」，以防筆記型電腦在未充電時任務不執行。
3.  點擊「確定」，系統可能會要求您輸入 Windows 帳戶的密碼。

## 4.3 測試與監控

*   **手動測試**: 在工作排程器中找到您建立的任務，按右鍵選擇「執行」，然後檢查 `log/daily_task.log` 檔案是否有新的日誌產生，以確認設定是否成功。
*   **日常監控**: 每日任務執行後，您應定期檢查 `log/daily_task.log` 的內容，確認 `[成功] 更新完成` 的訊息，並留意是否有錯誤報告。
